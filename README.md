# book-club
a short web comic!

features
moving components with 3D perspective
conditional buttons (to move forward)
randomizer and frame motion for cards
how to use/set up
You can just use the demo link; no further setup is needed.

tech stack
Next.js
Tailwind CSS
Frame Motion
why I made it
I made it because I wanted to try and make something more creative that would allow me to design a little more!

learning outcomes
I learned how to use frame motion for the cards and am definitely going to incorporate it into further projects! I also learned about switching states and how to make the Tailwind condiitonal to which current state. 

Challenges I faced
I faced a lot of issues with the design (even though it was my favorite part!), I spent a lot of time trying value to make sure everything looked right. Also the conditionals were quite hard at some time. I also lost around 1.5 hours on lapse :C so I defintely need to work on learning how to use that. Also the art was kinda hard for me but I decided to make a simpler version!
